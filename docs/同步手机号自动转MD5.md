# 同步入库时自动转换手机号

创建或编辑同步任务，在字段映射中选择手机号列后，可打开“明文手机号自动转 MD5”。默认关闭，旧任务保持原有行为。目标映射和实际目标列须为 String（实际列支持 Nullable / LowCardinality 包装）。

开启后，入库前逐行识别中国大陆 11 位明文手机号，沿用现有号码归一化规则，去除空格、括号、连字符及国际区号等，再生成 UTF-8 编码的 32 位小写 MD5。已有 MD5 不重复哈希，其他非手机号值保持原样；这不是任意字符串转 MD5，也不新增号码有效性校验。空值保持原有规则，手机号默认值也应用相同转换。

配置保存在任务表已有的 mapping_json 中，无需修改 MySQL 表结构。手动执行、定时执行、全量、增量和断点续传共用写入转换入口。源行和续传游标保持原值，目标只接收转换后的号码。转换字段不能同时用作稳定分段键或增量水位字段。

打开或关闭开关会改变任务映射指纹，不能沿用此前不同转换规则的断点。已写入的数据不会自动回填或改写；已有任务切换前应按现有重新执行流程处理，避免同表混入两种号码口径。未开启的旧任务不增加 JSON 字段，不影响历史断点指纹。

此功能只处理同步目标值，不会对源库、源快照或断点原始游标进行脱敏。MD5 是确定性哈希，不是加密。
