## 已实现

- 服务端 Session 登录、CSRF 校验、BCrypt 密码存储及旧摘要兼容校验。2026-10-20 起移除登录时自动升级旧摘要的行为，避免与只支持旧格式的部署共用元数据库时破坏其登录。
- 独立「系统 → 平台用户管理」菜单：新增账号、修改角色、禁用账号、重置密码。
- 首次登录强制改密、修改本人密码、退出所有设备、最后一个有效管理员保护。
- 数据源和数据源分组按所有者隔离；上传文件按用户目录隔离；历史文件只接受当前用户已分配的精确路径。
- 表目录及指定用户只读共享；共享者不能导出、修改、转授；撤销后后续请求立即失去访问权。
- 数据源删除或配置变化时清理关联表与授权；单纯改名保留共享。
- 表预览、结构、键、体检、统计的访问检查；导出、DDL、整理、清空要求所有者权限。
- 历史数据源显式分配；ClickHouse 历史表登记前验证其存在。管理员身份不自动获得业务数据所有权。
- 会话过期后退出登录按已退出处理；登录、登出前重新获取 CSRF token。
- 同步任务列表、详情、启停、取消、运行历史和文件去重记录均校验任务所有者；共享表不能用作同步来源或写入目标。
- 恢复受控同步、数据源一键同步和定时触发：调度器、XXL-JOB、异步线程从持久化任务归属恢复身份，禁用或未完成首次改密的账号不执行。
- 新同步目标登记为私有表；已有未分配表不得通过任务保存认领。目标登记和任务保存处于同一事务，并对目标记录加锁检查任务冲突。
- 节点工作流、仲裁工作流、查询工作流的配置和历史按所有者隔离；保存时校验所引用数据源或表。宽表标记只清理当前用户的其他标记。
- 历史归属页面增加任务和工作流分配，分配后保持停用；同步任务须与其数据源属于同一用户。
- 首页工作流统计改为当前用户的仲裁工作流；普通用户的连接选择只返回必要名称、ID 和状态信息。
- 已保存 SQL 与查询分组按所有者隔离：列表、详情、分组计数、新增、修改、移动和删除均校验归属；默认分组也只显示本人内容。归属登记失败会回滚创建操作。
- 历史资源归属页支持管理员分配未归属的 SQL，分配后归入接收者的默认分组，不执行 SQL、不授予表权限，也不自动继承旧分组。
- SQL 历史、可视化草稿和表筛选条件的浏览器缓存按用户 ID 隔离；退出或切换账号后，旧页面延迟回调不再读写缓存。旧版没有归属信息的本地缓存会清理，不自动归给下一位登录用户。
- 登录及身份接口返回 SQL 执行能力；数据探索页显示限制说明，禁用执行入口，并取消无权限时的打开即执行。编辑、保存、分组管理仍可用。
- 可视化配置恢复生成 SQL 文本：校验引用表属于本人，不访问业务数据库；`run=true` 试跑仍返回 403。原始 SQL、实际执行和结果导出继续受服务端限制。
